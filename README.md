# Ascension Tooltip

**AscensionTooltip** is an enhanced tooltip addon for **Project Ascension**. It provides detailed talent information and interactive spell-talent relationship insights to help players understand how their abilities interact.

## Key Features

*   **Visual Customization**: Full control over colors, opacity, and borders for a premium look.
*   **Smart Scaling**: Uses pixel-based MaxHeight with automatic width adjustment to prevent overlap.
*   **Data Management**: Includes a user whitelist to add spells/talents and a blacklist to exclude specific entries.
*   **Real-time Resolving**: Resolves spell names, IDs, and icons directly in the settings menu.
*   **Reporting Tools**: Easily share your local data via GitHub, CurseForge, or Raw Data to contribute to the community.
*   **Profile Management**: Save and reset configurations per character profile.
*   **Menu**: use the in add on menu or use /at

**AscensionTooltip** es un addon de descripción emergente mejorado para **Project Ascension**. Proporciona información detallada sobre los talentos e ideas interactivas sobre la relación entre hechizos y talentos para ayudar a los jugadores a comprender cómo interactúan sus habilidades.

## Características Principales

*   **Personalización Visual**: Control total sobre los colores, la opacidad y los bordes para una apariencia de alta calidad.
*   **Escalado Inteligente**: Utiliza una altura máxima basada en píxeles con ajuste automático de ancho para evitar que se superpongan.
*   **Gestión de Datos**: Incluye una lista blanca de usuario para añadir hechizos/talentos y una lista negra para excluir entradas específicas.
*   **Resolución en Tiempo Real**: Resuelve nombres de hechizos, IDs e iconos directamente en el menú de configuración.
*   **Herramientas de Reporte**: Comparte fácilmente tus datos locales a través de GitHub, CurseForge o datos sin procesar para contribuir a la comunidad.
*   **Gestión de Perfiles**: Guarda y restablece configuraciones por perfil de personaje.
